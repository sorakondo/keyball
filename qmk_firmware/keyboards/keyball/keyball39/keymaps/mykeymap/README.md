# Keyball39 mykeymap 配置表

`keymap.c` の配置を、日本語（JIS）配列として認識される場合の入力文字で表示しています。
OS の配列設定によって、記号の入力結果は異なります。キーマップ変更時はこの表も更新してください。

- 左右とも、実機を上から見た順序です。
- `↳` は下の有効なレイヤーのキーを使用します。
- `タップ / 長押し` の表記は、押し方で動作が変わるキーです。
- GUI は macOS の Command／Windows の Windows キーです。

## レイヤー0：通常

```text
           左手                              右手
 Q     W     E     R     T          Y     U     I     O     P
 A¹    S²    D³    F²    G          H     J     K     L    Enter⁴
 Z     X     C     V     B          N     M     ,⁵    .     /
```

| 印 | タップ | 長押し |
| --- | --- | --- |
| ¹ | A | 左 Ctrl |
| ² | S または F | 左 Shift |
| ³ | D | 左 Alt |
| ⁴ | Enter | 右 Ctrl |
| ⁵ | カンマ | スクロールモード |

最下段はコード上、左から次の配置です。実機ではトラックボールの位置により、一部のキーが存在しません。

```text
左手：左Ctrl  GUI  左Alt  英数/L1  Space/左Shift  Tab/L3
右手：Backspace  かな/L2  ↳  ↳  ↳  Esc
```

`英数/L1`、`かな/L2`、`Tab/L3` はタップで文字・言語キー、長押しで指定レイヤーを有効にします。

同時押し：J＋K で左クリック、K＋L で右クリック。

## レイヤー1：記号

「英数」を長押しして使用します。T の位置は縦棒 `|`（`JP_PIPE`）です。

```text
           左手                              右手
 Esc   &     '     (     |          \     (     )     <     >
 ~     $     %     ^     =          _     {     }     ;     :
 -     !     @     #     ?          `     [     ]     '     "
```

最下段はすべて `↳` です。

## レイヤー2：数字・カーソル

「かな」を長押しして使用します。

```text
           左手                              右手
 -     7     8     9     +         Home  PgUp  PgDn  End   Bksp
 /     4     5     6     *          ←     ↓     ↑     →    Delete
 .     1     2     3     =        Alt+←  左Click ↳  右Click  ↳
```

```text
最下段
左手：:  0  右Alt  ↳  ↳  ↳
右手：↳  ↳  ↳  ↳  ↳  ↳
```

## レイヤー3：ファンクション・操作

Tab を長押しして使用します。このレイヤーではスクロールモードも有効になります。

```text
           左手                              右手
 明るさ↑ F7    F8    F9    F10       ⇧GUI+← ⇧GUI+↓ ⇧GUI+↑ ⇧GUI+→  ↳
 明るさ↓ F4    F5    F6    F11         GUI+←  GUI+↓  GUI+↑  GUI+→  ↳
 PrtSc   F1    F2    F3    F12         Alt+← 左Click   ↳   右Click  ↳
```

`⇧` は Shift です。

```text
最下段
左手：右Ctrl  ↳  ↳  ↳  ↳  ↳
右手：↳       ↳  ↳  ↳  ↳  ↳
```
